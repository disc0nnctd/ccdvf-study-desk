# Northstar · CCDV-F Practice

Quiz-only public GitHub Pages build. It includes the embedded 567-question practice bank (467 community + 100 original), four fixed mocks, an exam-weighted mock, weight-ordered topic drills, a Learning plan page, answer explanations, browser-local progress, and progress backup import/export. No course-reading modules are included.

The 467 reviewed community questions are MIT licensed; see `LICENSE-CCDVF-COMMUNITY.txt`. The 53 original practice questions and app interface are independent study materials. This is not official exam content or endorsed by Anthropic. Verify exam details against official sources.

To deploy: enable GitHub Pages from the `main` branch, root folder.
